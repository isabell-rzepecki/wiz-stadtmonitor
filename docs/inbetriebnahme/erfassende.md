# Ablaufkarte Erfassende

**Was Sie brauchen:** die Einladungskarte (Code und Adresse der Erfassungsseite) und ein Smartphone oder Tablet.

1. **Ausprobieren:** Auf der Erfassungsseite „Ohne Code ausprobieren“ wählen. Dabei wird nichts gespeichert.
2. **Zugang:** den Code eingeben. Die App merkt sich nur eine pseudonyme Erfasser-ID; die Karte danach vernichten.
3. **Offline nutzen:** die Seite einmal mit Netz öffnen und „Zum Startbildschirm hinzufügen“. Danach funktionieren Erfassen und Speichern auch ohne Netz.
4. **Eigentum und Vermietung:** Gebäude antippen und die Kategorie wählen.
   - Bei Unternehmen, Genossenschaften, der öffentlichen Hand und Kirchen den Namen eintragen.
   - Beleg und Sicherheit angeben.
   - **Nie:** Namen aus Grundbuchauszügen Dritter, Klingelschilder, Fotos von Personen oder Hausnummern im Freitext.
5. **Mietangabe:** nur mit der Einwilligung der Mietenden, die sie selbst ankreuzen. Den angezeigten **Widerrufscode** den Mietenden geben (notieren oder fotografieren lassen).
6. **Export:** Über „Einträge“ und „Exportieren“ entsteht eine verschlüsselte Datei; nur die Prüfgruppe kann sie lesen. Diese Datei an die Prüfgruppe weitergeben. Erst wenn die Prüfgruppe den Eingang bestätigt hat, „Exportierte löschen“.
7. **Datenschutz:** Den Hinweis in der App („Datenschutz“) auf Nachfrage zeigen. Wer widersprechen will, wendet sich an die Kontaktadresse dort.
