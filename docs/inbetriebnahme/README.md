# Inbetriebnahme der Erfassung Wohnen und Eigentum

Reihenfolge (Checkliste: Issue 53). Je Rolle gibt es eine Karte zum Ausdrucken. Namen gehören nicht ins Repository.

1. **Verantwortliche Stelle** benennen und mit Funktionsadresse in `config/stadt.json` eintragen (`wohnen_eigentum.erfassung.datenschutz`).
2. **Prüfgruppe:** Generalprobe, Schlüssel, Papiersicherung → [pruefgruppe.md](pruefgruppe.md)
3. **Ausgabestelle:** Codes ausgeben → [ausgabestelle.md](ausgabestelle.md)
4. `config/stadt.json` committen und veröffentlichen.
5. **Erfassende:** Zugang, Erfassen, Export → [erfassende.md](erfassende.md)
6. Probelauf: ein Eintrag je Formular, Export, Einlesen, Freigabe zu zweit, Veröffentlichen (Prüfgruppe).
